# Breast Cancer Classification using K-Nearest Neighbors

A machine learning classification project that uses the **K-Nearest Neighbors (KNN)** algorithm to classify breast cancer cases based on diagnostic features.

## Overview

This project demonstrates the application of the K-Nearest Neighbors algorithm to a binary classification problem.

The workflow includes data inspection, feature preparation, feature scaling, model training, prediction, and evaluation on unseen test data.

```text
Dataset
   ↓

   ↓
Feature / Target Separation
   ↓

   ↓

   ↓

   ↓
Predictions
   ↓
Model Evaluation
